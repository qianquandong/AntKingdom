## 地表不能直接压缩到一行

在 `015d631` 的 `GameScene.addSurfaceBackdrop` 中，`SKSpriteNode(texture:size:frame.size)` 会把原本432×96pt的贴图压成432×48pt。本批要求 **等比裁切**：

- 完整运行时源：1296×288；当前地图九列一行需要读取像素矩形 **x=0, y=72, width=1296, height=144**（左上像素坐标），再显示432×48pt。
- 对应归一化纹理矩形 `(0, 0.25, 1, 0.5)`。可用子纹理或等价裁切节点，Claude 负责平台实现；不要把未裁切的整张纹理强设成一行大小。
- 地表随世界镜头缩放和平移，不能跟HUD固定。仅装饰层，不改 `.surface` / `E` 的通行、命中、入口、兜底收入或地图边界；确保中间 `E` 入口仍由现有通路节点清晰绘制，草皮不能盖住它。
- 其他地图尺寸变化时等比适配和裁切，不横向硬拉伸。超出当前验证宽度的地图在 A04 单独检查，不虚称本图可无缝重复。

[裁切对照图](qa/surface-device-crop@3x.png)是QA证据，不是第五张运行时资源。

## 裂纹、土屑与事件

- 第1次有效命中：显示 crack_1；第2次：原地替换 crack_2，并按PRD提供短时碎屑反馈；第3次完成：清掉该格裂纹，更新正式通路。不能改三次命中、可挖边界、路径/拥堵/成本规则。
- 两级裂纹使用完整144px画布，不按可见边界分别裁切、居中、旋转或缩放，不同时叠加两级。原裂纹主干保留，新分叉向外增长；第三次没有永久“破坏洞”贴图。
- 土屑是土棕色小颗粒，不是 `ant_cargo` 或资源收益。反馈绑定实际有效命中/开通事件一次，不能每次 `render` 都重播；已挖、不可挖、拖动/缩放不得误触发。开通时可保留原有短 burst，但同一事件不重复创建。
- 现有 `burst` 契约为普通6颗、Reduce Motion 1颗仅淡出、约0.35s后清理；保持这些边界与设置响应，不增加常驻粒子系统。移除后的节点/动作不能累积。
- 地形、碰撞、离线、收益都不由透明轮廓、粒子消失或动画完成驱动。存档恢复按真实挖掘进度还原静态裂纹，不能重播旧奖励/开通事件。

## 桌面验收结果

4/4尺寸、sRGB、透明/不透明状态正确。三个透明图外沿alpha为0，alpha>8的图形距四边至少留15%画布；第一级修订后无原来的远端杂点。三个现有 Soil 变体、白/深色底与灰度下均检查；48pt第2级比第1级明显更深且有新增分叉。颗粒在12pt/8pt只承担短时土屑提示，不承担可读文字或计数。

裂纹1的205个主体像素（alpha≥96）在裂纹2中全部能在1个运行时像素范围内找到对应像素：**205/205，100%**，门槛97%。这是“主干仍在原位”的工程检查，不宣称两幅图每个像素完全一致，也不能替代设备录像。地表已检查完整/中间裁切/432×48逻辑尺寸，比例未压扁。
