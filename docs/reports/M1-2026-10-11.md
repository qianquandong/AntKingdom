## 本次完成的行为

- **C01**：核心包地图解析与校验（与 `tools/check_map.py` 同规则，内置地图与 `design/map_backyard.txt` 一致）；
  `GameCommand`（tap / build / move / 孵化 / 设置 / reset）、`GameState`（可序列化、完整校验）、
  时间接口（`MonotonicClock`、`WallClock`、`TickAccumulator` 单帧上限 1 秒、离线封顶 3600 秒）；手动点击 ≤ 8 次/秒、长按 5 次/秒。
- **C02**：BFS（起点按 (y, x) 排序，邻居上/左/右/下）、最多 4 条候选路线、共享格负载（容量 8）、
  逐只确定性分流（ε 1e-10，最多 256 步），与 `economy_sim.py` 逐行对应。
- **C03**：0.25 秒步进；源优先级 patch > sap > surface；仓容/有限源守恒（只扣实际入库量）；孵化槽与人口上限 24；
  离线按 25% 运输率、一小时封顶；600 秒固定操作回放与 Python **逐秒**一致。
- **C04**：SpriteKit 地图（48pt 格）、相机（拖动 + 双指缩放，夹紧到 HUD/底栏之外的可视区）、
  点击挖土（3 次一格）与长按挖土、拖动/缩放不误挖、源/Queen/Pantry 选中与底部面板、HUD（Food / Ants / Eggs、当前源、Food/min、Trip）、
  繁忙格用颜色 + 三横线图标双重标记、非法点击抖动反馈、英文提示条。文字全部原生 SwiftUI，来自 PRD 附录 A。

## 如何启动 / 复现

```bash
swift test --package-path Packages/AntKingdomCore
swift run --package-path Packages/AntKingdomCore ak-sim > build/swift_core.json
python3 tools/diff_core.py build/swift_core.json build/core-diff.md
```

Debug 构建可用 `-ak-scenario fresh|connected|busy|...` 直接进入固定状态（见 `docs/BUILD.md`）。
