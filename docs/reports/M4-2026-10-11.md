## 本次完成的行为

- **章节目录与目标**：三个主目标（接通 Cookie Crumb、建成 Pantry、24 只且 1,100 Food）全部达成即完成本章、解锁下一章；
  三个探索目标（接通 Sugar Drop、接通 Sap Root、冻结人口与源后布局改善 ≥5%）不是门槛。
- **跨章状态**：每章独立存档；只推进当前章节；离线只结算离开时的当前章节一次；切换章节先保存，再从“现在”起载入目标章节（非活动章节不产粮）。
- **完成页**：Colony Ready! 卡片列出主/探索目标勾选状态，Next Colony / Keep Building / Start This Colony Again（二次确认）；
  每局只宣布一次；不推销任何商品或广告。发行轨隐藏核心版的 “Colony complete! Try a new layout.” 引导（D-08）。
- **章节页**：Choose a Colony；锁定章节显示 “Complete the previous colony to unlock.” 且不可打开；当前章节可重玩。
- **重玩与重置**：重玩只重置本章（保留解锁、已获目标、设置、购买、奖励账本）；设置里的 Reset All Progress 清空全部章节与解锁，保留设置、购买权益与奖励次数。
- **存档鲁棒性**：全局进度主档 + 备份；两份都坏时从各章存档推导解锁，不静默丢失；单章存档坏只影响该章（重开该章需二次确认）；新 schema 不覆盖。
- **文案**：RELEASE_SCOPE 第 6 节加“最大字符数”列并登记 C10 新文案 16 条；`export_strings.py` 另导出只进发行轨的 `Release.xcstrings`；
  `check_strings.py` 校验两表 ID 唯一、不重用核心 ID、无中文、占位符与长度。
