## 本次完成的行为

- **C05 Pantry 与引导**：Build Pantry / Move 进入 2×2 摆放预览；合法 = 绿色实线框 + 勾，非法 = 橙色虚线框 + 叉（不只靠颜色）；
  非法或余额不足时 Confirm 不可用、不扣 Food；Cancel 无任何变化；摆放时不挖土；首次建造扣 50，之后移动免费，旧位置保留通路；
  移近后显示真实改善 `Faster route! +x% Food/min`。英文首局引导 dig → hatching → save food → pantry → move，
  出现繁忙格时优先提示绕路；建仓建议位置取离当前源装货口最近的合法 2×2。补给刷新发 `Food arrived` 提示。
- **C06 存档与生命周期**：schema v1 存档外层（App 版本、保存时间、墙钟高水位、序号）；原子写入 + 写前备份；
  主档坏用最近有效备份，主备都坏显示英文错误 + Try Again / Start Over（二次确认），**不静默清档**；
  新 schema 存档不降级不覆盖；冷启动结算一次离线（25%、封顶 1 小时、时间回拨不给负时间也不重复领取）；
  关键操作后立即保存、未完成格点击每秒最多存一次、另有 30 秒自动保存；离线 ≥ 60 秒显示 Welcome Back，只显示实际搬入的 Food。
- **C07（部分）**：资源 ID → 运行时名称约定（63 个，`design/asset_runtime_names.json`）及客户端整组加载（隧道 16 遮罩 N1 E2 S4 W8、
  蚂蚁三姿态帧、源有货/空盘、卵两态、裂纹两级等），缺任何一个名称就整组保留占位；
  七类音效 + 触觉统一出口，按 Sound / Haptics 设置过滤，ambient 会话遵守静音开关；
  减少动态（系统设置或 Debug 参数）：碎屑只淡出、非法点击闪框代替抖动、前沿提示不呼吸、提示条只淡入淡出。
  **正式资源集成 BLOCKED**：A01–A03 尚未交付。
- **C08（部分）**：Mac CI（Linux + macOS 核心包、工程漂移、Python ↔ Swift 差分报告、标准 + 小屏 UI 测试、Pantry 操作录像、
  场景与离线截图）；TestFlight 配置无签名真机架构编译 + `ci/check-release-binary.sh`（版本/构建号、最低 iOS 17.0、仅 iPhone、
  调试入口不在二进制中、未链接 StoreKit / AdSupport / AppTrackingTransparency）；资源就绪检查 `tools/check_assets.py`。
