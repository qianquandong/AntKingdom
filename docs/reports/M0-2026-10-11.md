## 如何启动 / 复现

```bash
python3 -m unittest discover -s tests -v
swift test --package-path Packages/AntKingdomCore
xcodegen generate --spec ios/project.yml
xcodebuild -project ios/AntKingdom.xcodeproj -scheme AntKingdom -destination 'platform=iOS Simulator,name=iPhone 17' test
```

Xcode：打开 `ios/AntKingdom.xcodeproj`，选 `AntKingdom` scheme 与任一 iPhone 模拟器运行。
