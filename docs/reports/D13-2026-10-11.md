## 1. 根因

`LifecycleCoordinator` 用同一个墙钟高水位（`wallHighWater`）同时表示“见过的最大时间”和“离线起点”，
`save()` 每次都把它推进到“现在”。回到前台时，只要 `.active` 之前发生一次保存，离线起点就被推到回来那一刻，
`.active` 结算 0 秒、不弹总结。

实际触发者：SpriteKit 的恢复首帧可能早于 SwiftUI 处理 `.active`。这一帧的帧间隔被封顶为 1 秒（Food 只多约 2），
距上次保存已超过 30 秒，于是触发自动保存。与 CI 38172213454 attempt 2 的证据一致：后台约 65 秒（录像抽帧）、
回来后 Food 1→3、进程未重启（pid 不变）、没有 Welcome Back。

同一缺陷的其他形态：后台期间任何保存后被强杀，冷启动只从那次保存起算（少算）。`.background` 回调迟到或根本
没送达时，原实现也会漏算整段离开。

## 2. 最小复现（修复前稳定失败）

只用原有 API 的两条测试，在修复前的实现（51c112b）上 swift:6.2 中 **2/2 失败**：

```text
D13LifecycleTests.testKillAfterABackgroundSaveStillSettlesFromDeparture : XCTAssertEqual failed: ("570.0") is not equal to ("600.0")
D13LifecycleTests.testSaveBetweenBackgroundAndActiveDoesNotEatTheOfflineInterval : XCTUnwrap failed: expected non-nil value of type "OfflineSummary" - the 65 s away must be settled
Executed 2 tests, with 2 failures
```

第一条对应 CI 的实际时序：后台 → 65 秒 → 恢复首帧的保存 → `.active`。

## 3. 修复与唯一负责人

| 事件 | 负责人 | 规则 |
|---|---|---|
| 开始离线 | `enterBackground()` 或帧停顿检测 | 冻结 `awayReference = max(高水位, 实际离开时刻)`；实际离开时刻 = 最后一个前台帧的墙钟（回调迟到时更早） |
| 离开期间的保存 | `save()` | 存档时间记为 `awayReference`，不推进高水位：保存不能吃掉未结算区间，冷启动也从离开时刻起算 |
| 恢复首帧 | `admitForegroundFrame()` → `.hold` | `.active` 处理前不推进、不自动保存 |
| 结算 | `becomeActive()`；或帧停顿 > 5 秒且没有后台记录 → `.resumed` | 同一区间恰好一次；重复事件、短暂 inactive、5 秒内卡顿不结算；离开时刻计入高水位，回拨再拨回不重复 |
| 恢复在线 | 结算后 | 清空 `awayReference` 与最后帧；下一帧重新计帧 |

两路信号：SwiftUI `scenePhase` 与 UIKit `didEnterBackground` / `didBecomeActive`，协调器对重复事件幂等。
核心 AntKingdom（AppModel）与发行 CrumbKingdom（CampaignModel → CampaignCoordinator）走同一规则；
全屏奖励广告（只在发行轨）原先只在结束时 `restartFrameClock()`，Codex 复核发现广告中按 Home / 关闭前出帧仍会误结算（D-14），
已改为生命周期的有意暂停状态，见 [D14 报告](https://github.com/qianquandong/AntKingdom/blob/claude/m5-ads/docs/reports/D14-2026-10-12.md)。核心测试包没有广告。
PRD 规则不变：离线 25%、最多模拟 1 小时（所有时钟）、离线不享受 Foraging Boost、不足 60 秒不弹总结但照常结算。

诊断（仅 Debug）：`LifecycleTrace` 环形日志（序号、进程号、事件、墙钟、单调时钟、后台标记、高水位、离开基准、
最后帧、保存原因/结果、结算区间与收益、总结呈现），只在事件发生时记录；UI 测试从隐藏元素 `debug.lifecycle` 读取，
Debug 设置页 “Copy Lifecycle Log” 复制到剪贴板。Release 检查确认 `debug.lifecycle` 等标记 absent。
