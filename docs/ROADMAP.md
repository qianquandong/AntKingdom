# 后续路线图与旧版归档

当前需求仅以 [PRD v0.2](PRD.md) 为准。这里记录暂缓项目，不构成首版承诺。

旧完整设计：[v0.1 历史 PRD](https://github.com/qianquandong/AntKingdom/blob/3bd2062033cb5c2fcc1ff275c486cbee5e3a67df/docs/PRD.md)。旧四地层布局 [map_backyard.txt](../design/map_backyard.txt) 作为草案保留，不再被默认加载。

| 后续阶段 | 候选功能 | 恢复前必须补充的证据 |
|---|---|---|
| 核心延长 | 更多运输目标、地图变化、人口上限后的资源消耗 | 玩家理解并主动优化路线，饱和后的目标确有需求 |
| 成长系统 | Queen 等级、Dig 升级、房间等级 | 分钟与小时尺度的真实游玩节奏，不靠预设直线距离模拟 |
| 内容扩展 | 四地层、根系、最终宝石、第二世界 | 制作成本、内容消耗速度、真实地图与路径基准 |
| 多源经营 | Jobs、源优先级、多仓库 | 跨源共享负载、稳定分配、复杂度是否值得 |
| 一项可选奖励广告 | 明确一次奖励与可选触发 | 单独模拟奖励、频次及非广告体验，实测使用行为 |
| 一项外观商品 | 房间或蚂蚁外观 | 审美吸引力、展示空间、定价与购买意愿验证 |
| 完整商业发行 | 更多付费品、长期活动、云存档 | 留存、收入、内容成本与获客的实际数据 |

撤回旧脚本的 `--ads`、`--crew`、`--casual`、`--layout` 结论。只模拟离线翻倍不能代表所有广告产品；额外施工队只有在实际存在多个并行任务且产生有意义收益时才能评估。当前首版没有建设队列，因此不能销售施工队或推算其价值。

原稿的八天推进表不再是验收依据。以后如需恢复长线模拟，应从保存的真实格网、路径、源余量与状态事件出发，明确玩家行为脚本与敏感性范围，并区分设计假设和观测数据。
